# Concept

Common Ground is a conceptual translation layer between human intention and machine execution.

## Six Layers

1. **Intent** — what the human wants.
2. **Context** — why, where, and under which conditions.
3. **Interpretation** — what the system believes the human means.
4. **Representation** — a structured form both sides can work with.
5. **Action** — what the machine does.
6. **Feedback** — what returns to the human and changes the next iteration.

The important unit is not the command.

The important unit is the loop.
